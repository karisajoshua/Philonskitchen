# Philon’s Kitchen

Cinematic Kenyan culinary website built with Next.js, React, TypeScript and GSAP.

## Start

```bash
npm install
npm run dev
```

## Assets

Place approved, optimized culinary photographs under `public/images/` or connect a Supabase Storage public bucket using `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_MEDIA_BUCKET`.

The initial homepage includes intentional art-directed placeholder dish compositions until approved Philon’s Kitchen imagery is uploaded. Do not present AI-generated images as documentary photographs of the chef’s actual work.

## Pricing

Displayed catering rates are chef labour fees only. Ingredients, transport, equipment and staff may be charged separately. Booking is subject to confirmation.
